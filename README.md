| Источник | Формат | Период |

| [Данные о поездках такси в Нью-Йорке](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) | Parquet | Январь 2024 |
| [Данные о поездках такси в Чикаго](https://data.cityofchicago.org/Transportation/Taxi-Trips-2024-/ajtu-isnz/about_data) | XML | Январь 2024, до 10 000 записей |

| [Информация об экстремальных событиях в городах](https://www.ncei.noaa.gov/pub/data/swdi/stormevents/csvfiles/) | CSV + текст | Январь 2024, штаты Нью-Йорк и Иллинойс |
