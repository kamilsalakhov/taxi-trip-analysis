# taxi-trip-analysis

## Описание проекта

**Тема:** Анализ данных о поездках такси для выявления факторов, влияющих на длительность поездок, и временных паттернов.

Цель проекта — исследовать закономерности поездок такси в Нью-Йорке, определить влияние погодных условий и экстремальных событий на продолжительность поездок, а также выявить изменения транспортной активности в зависимости от времени суток и дня недели.

## Описание источников данных

### 1. NYC Yellow Taxi Trip Records (Parquet)

Официальный набор данных Комиссии по такси и лимузинам Нью-Йорка (NYC TLC), содержащий сведения о поездках жёлтых такси за январь 2024 года.

**Основные характеристики:**
- Дата и время начала и окончания поездки.
- Идентификаторы районов посадки и высадки пассажиров.
- Расстояние поездки.
- Количество пассажиров.
- Стоимость поездки и дополнительные платежи.

**Назначение:** основной источник для анализа продолжительности поездок, выявления часов пик, суточных и недельных закономерностей, а также исследования зависимости времени поездки от расстояния и других факторов.

### 2. Open-Meteo Historical Weather API (JSON)

Исторические почасовые метеорологические данные для Нью-Йорка за январь 2024 года, получаемые через API Open-Meteo.

**Основные характеристики:**
- Температура воздуха.
- Относительная влажность.
- Количество осадков, дождя и снега.
- Скорость ветра.
- Код погодных условий.
- Дата и время наблюдения.

**Назначение:** исследование влияния погодных условий на продолжительность поездок такси. Данные могут быть сопоставлены с поездками по дате и часу начала поездки.

### 3. NOAA Storm Events Database (CSV)

Официальная база Национального управления океанических и атмосферных исследований США (NOAA), содержащая информацию об экстремальных погодных явлениях.

**Основные характеристики:**
- Тип погодного события.
- Дата и время начала и окончания события.
- Географическое расположение.
- Описание погодного явления.
- Сведения о последствиях и причинённом ущербе.

**Назначение:** анализ возможного влияния экстремальных погодных явлений на продолжительность поездок и транспортную активность.

Данные NOAA охватывают различные территории штата Нью-Йорк, поэтому для городского анализа необходимо дополнительно учитывать географическое расположение событий.

### 4. Когда люди чаще ездят на такси? Исследование (HTML)

Русскоязычная статья, посвящённая исследованию спроса на услуги такси и закономерностей использования такси в зависимости от времени.

**Основные характеристики:**
- Текстовое описание результатов исследования.
- Сведения о периодах повышенного спроса.
- Информация о временных особенностях использования такси.

**Назначение:** дополнительный текстовый источник для изучения временных закономерностей спроса на такси и сопоставления описанных тенденций с результатами анализа данных Нью-Йорка.

### 5. От чего зависят цены на такси? (HTML)

Информационная статья Роскачества, посвящённая факторам, определяющим стоимость поездок на такси.

**Основные характеристики:**
- Описание факторов формирования стоимости поездок.
- Влияние спроса и времени суток.
- Влияние погодных и дорожных условий.
- Особенности динамического ценообразования.

**Назначение:** выявление дополнительных факторов, связанных с условиями поездок, которые могут учитываться при интерпретации результатов анализа.

### 6. Спрос на такси в России: дни и часы, когда автомобили заказывают чаще всего (HTML)

Аналитическая публикация о распределении спроса на услуги такси в России по дням недели и времени суток.

**Основные характеристики:**
- Статистические сведения о спросе на такси.
- Распределение заказов по времени суток.
- Особенности спроса в будние и выходные дни.
- Описание периодов повышенной транспортной активности.

**Назначение:** изучение временных закономерностей спроса на такси и сравнение опубликованных наблюдений с результатами анализа поездок в Нью-Йорке.

## Форматы и методы обработки данных

В проекте используются структурированные, полуструктурированные и неструктурированные источники данных.

| Формат | Метод загрузки | Инструменты |
|---|---|---|
| Parquet | Чтение файла | pandas, PyArrow |
| JSON | HTTP-запрос к API | requests, pandas |
| CSV | Чтение табличных данных | pandas |
| HTML | Загрузка веб-страниц и извлечение текста | requests, BeautifulSoup |

Для обработки и анализа данных используется Python с библиотеками pandas, requests, BeautifulSoup и PyArrow.
